# yzj

这是由 whyzjay 上传的项目（仓库 yzj）。

主要文件：
- main.py — 主脚本（位于仓库根目录）
- scripts/loaddata.py — 数据加载脚本
- scripts/dav2.py — 另一个辅助脚本

快速开始：

1. 建议使用虚拟环境：

`powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
`

2. 运行：

`powershell
python main.py --help
`

依赖信息请参考 equirements.txt。
